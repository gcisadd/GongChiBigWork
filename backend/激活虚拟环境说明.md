# Windows 虚拟环境激活问题解决方案

## 问题说明

在 Windows 系统上，根据使用的终端不同，激活虚拟环境的方式也不同。如果直接使用 `venv\Scripts\activate` 可能会报错。

## 解决方案

### 方案一：CMD 命令提示符（推荐）

```cmd
# 进入后端目录
cd backend

# 激活虚拟环境
venv\Scripts\activate.bat
```

激活成功后，命令提示符前会显示 `(venv)`。

### 方案二：PowerShell

如果使用 PowerShell，需要使用 `.ps1` 文件：

```powershell
# 进入后端目录
cd backend

# 如果遇到"无法加载文件，因为在此系统上禁止运行脚本"的错误
# 先执行以下命令设置执行策略（仅需执行一次）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后激活虚拟环境
venv\Scripts\Activate.ps1
```

### 方案三：Git Bash（你当前使用的终端）

**重要**：Git Bash 不能直接执行 `.bat` 文件，必须使用 `source` 命令！

如果使用 Git Bash：

```bash
# 进入后端目录
cd backend

# 激活虚拟环境（注意：使用正斜杠 /，不是反斜杠 \）
source venv/Scripts/activate
```

**常见错误**：
- ❌ `venv\Scripts\activate.bat` - Git Bash 无法执行 .bat 文件
- ✅ `source venv/Scripts/activate` - 正确的方式

### 方案四：VS Code 终端

VS Code 的终端会自动识别虚拟环境，通常可以直接使用：
- 如果使用 PowerShell：`venv\Scripts\Activate.ps1`
- 如果使用 CMD：`venv\Scripts\activate.bat`

## 验证激活是否成功

激活成功后，命令提示符前会显示 `(venv)`，例如：

```
(venv) E:\GongChiBigWork\backend>
```

## 退出虚拟环境

无论使用哪种方式激活，退出虚拟环境都使用：

```bash
deactivate
```

## 常见错误及解决方法

### 错误 1：PowerShell 执行策略限制

**错误信息**：
```
无法加载文件 venv\Scripts\Activate.ps1，因为在此系统上禁止运行脚本
```

**解决方法**：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 错误 2：找不到 activate 文件

**原因**：虚拟环境未正确创建

**解决方法**：
```bash
# 删除旧的虚拟环境
rmdir /s venv

# 重新创建虚拟环境
python -m venv venv
```

### 错误 3：Python 命令不存在

**原因**：Python 未安装或未添加到 PATH

**解决方法**：
1. 确认已安装 Python 3.10+
2. 在命令行输入 `python --version` 检查是否可用
3. 如果不可用，需要将 Python 添加到系统 PATH 环境变量

## 推荐做法

1. **使用 CMD**：最简单，直接使用 `venv\Scripts\activate.bat`
2. **使用 VS Code**：VS Code 会自动识别虚拟环境
3. **使用 PowerShell**：需要先设置执行策略

## 快速启动脚本

你也可以创建一个批处理文件来快速激活虚拟环境：

**创建 `start.bat` 文件**（放在 backend 目录下）：

```batch
@echo off
call venv\Scripts\activate.bat
python run.py
```

然后双击 `start.bat` 即可启动服务。
