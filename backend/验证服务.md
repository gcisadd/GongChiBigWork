# 后端服务启动成功验证指南

## 方法一：查看终端输出（最简单）

启动成功后，终端会显示类似以下信息：

```
INFO:     Started server process [xxxxx]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [xxxxx] using WatchFiles
```

**关键标志**：
- ✅ 看到 `Uvicorn running on http://0.0.0.0:8000` 表示服务已启动
- ✅ 看到 `Application startup complete` 表示应用初始化完成
- ✅ 没有红色错误信息

## 方法二：访问健康检查接口（推荐）

在浏览器中访问：

```
http://localhost:8000/api/health
```

**成功响应**：
```json
{
  "status": "ok",
  "message": "服务运行正常"
}
```

## 方法三：访问根路径

在浏览器中访问：

```
http://localhost:8000/
```

**成功响应**：
```json
{
  "message": "GongChiBigWork API 服务",
  "version": "1.0.0",
  "docs": "/api/docs"
}
```

## 方法四：访问 API 文档（最直观）

在浏览器中访问：

```
http://localhost:8000/api/docs
```

**成功标志**：
- ✅ 看到 Swagger UI 界面
- ✅ 显示所有 API 接口列表（认证、文档管理、个人信息）
- ✅ 可以展开查看接口详情

## 方法五：使用 PowerShell 测试（命令行）

在 PowerShell 中执行：

```powershell
# 测试健康检查接口
Invoke-RestMethod -Uri "http://localhost:8000/api/health" -Method Get

# 测试根路径
Invoke-RestMethod -Uri "http://localhost:8000/" -Method Get
```

**成功响应**：会显示 JSON 格式的响应数据

## 方法六：使用 curl 测试（如果安装了 curl）

```bash
# 测试健康检查
curl http://localhost:8000/api/health

# 测试根路径
curl http://localhost:8000/
```

## 快速验证脚本

创建一个 PowerShell 脚本 `验证服务.ps1`：

```powershell
Write-Host "正在验证服务状态..." -ForegroundColor Yellow

try {
    $response = Invoke-RestMethod -Uri "http://localhost:8000/api/health" -Method Get -TimeoutSec 5
    Write-Host "✅ 服务运行正常！" -ForegroundColor Green
    Write-Host "响应: $($response | ConvertTo-Json)" -ForegroundColor Cyan
    Write-Host ""
    Write-Host "访问以下地址查看 API 文档：" -ForegroundColor Yellow
    Write-Host "http://localhost:8000/api/docs" -ForegroundColor Cyan
} catch {
    Write-Host "❌ 服务未启动或无法访问" -ForegroundColor Red
    Write-Host "错误信息: $($_.Exception.Message)" -ForegroundColor Red
}
```

## 常见问题排查

### 1. 端口被占用

如果看到 `Address already in use` 错误：
- 检查 8000 端口是否被其他程序占用
- 修改 `run.py` 中的端口号

### 2. 模块未找到

如果看到 `ModuleNotFoundError`：
- 确保虚拟环境已激活
- 运行 `pip install -r requirements.txt`

### 3. 数据库错误

如果看到数据库相关错误：
- 检查数据库文件权限
- 确保 `backend` 目录有写入权限
